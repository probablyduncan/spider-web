visit: https://spiders.duncanpetrie.com

this is:
1. a website ([/packages/website](https://github.com/probablyduncan/spider-web/tree/main/packages/website)) which shows all the other spiders that are currently on the site.
2. a browser extension ([/packages/extension](https://github.com/probablyduncan/spider-web/tree/main/packages/extension)) which lets you take your spider on the road, and will also occasionally run another spider across your screen.
